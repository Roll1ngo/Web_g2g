Політика безпеки та конфіденційності

Wow Service Portal

Wow Service Portal (далі «Ми», «Наш сервіс») прагне забезпечити максимальний рівень безпеки та конфіденційності для всіх наших користувачів (далі «Ви», «Користувач»). Ця Політика описує, як ми збираємо, використовуємо, зберігаємо та захищаємо Ваші дані при користуванні нашим сервісом продажу ігрового золота WoW з інтеграцією в Telegram.

1. Збір та використання інформації

Ми збираємо інформацію, необхідну для надання та покращення наших послуг. Це включає:

  • Персональні дані: Ім'я користувача Telegram, ідентифікатор Telegram (**Telegram ID**) для зв'язку з ботом, адреса електронної пошти. Ця інформація використовується виключно для Вашої ідентифікації в системі, зв'язку та надання доступу до функціоналу сервісу.
  • Фінансові дані: Інформація про баланс, історію транзакцій, обрані методи виплат (реквізити банківських карток, Payoneer, USDT BEP20/Binance USDT). Ці дані використовуються виключно для здійснення виплат та ведення фінансової звітності. Ми не зберігаємо повні номери банківських карток або повні платіжні дані Payoneer. Зберігається лише та інформація, яка необхідна для ідентифікації Вашого рахунку та проведення транзакцій, без компрометації повної платіжної інформації.
  • Дані ігрового процесу: Інформація про ігрові сервери, кількість золота, стратегії продажу, скріншоти та відеозаписи відправок золота. Ці дані потрібні для виконання замовлень, контролю якості та вирішення спірних ситуацій. Відеозаписи є ключовим елементом гарантії Вашої оплати.
  • Технічні дані: IP-адреса, тип пристрою, дані браузера, час доступу. Ця інформація збирається для аналізу використання сервісу, запобігання шахрайству та покращення роботи системи.

2. Зберігання та захист даних

Ми вживаємо всіх можливих заходів для захисту Ваших даних:

  • Шифрування: Вся передача даних між Вами та нашим сервісом здійснюється через захищені протоколи (HTTPS).
  • Обмежений доступ: Доступ до Ваших персональних та фінансових даних мають лише уповноважені співробітники, яким це необхідно для виконання їхніх обов'язків.
  • Фізична безпека: Наші сервери розташовані в захищених центрах обробки даних з контрольованим доступом.
  • Резервне копіювання: Регулярне резервне копіювання даних забезпечує їх збереження у випадку непередбачених обставин.
  • Відеозаписи: Відеозаписи відправок золота зберігаються на захищених серверах і використовуються виключно для підтвердження факту передачі та вирішення спорів. Вони не поширюються і не передаються третім особам.

3. Розкриття інформації третім сторонам

Ми ніколи не продаємо, не обмінюємо та не передаємо Ваші персональні дані третім сторонам, за винятком випадків, передбачених цією Політикою або чинним законодавством:

  • Платіжні системи: Для здійснення виплат Ваші фінансові дані можуть бути передані відповідним платіжним системам (банки, Payoneer, криптовалютні біржі). Передається лише мінімально необхідна інформація для проведення транзакції.
  • Правоохоронні органи: У виняткових випадках, згідно з судовим рішенням або обґрунтованим запитом правоохоронних органів, ми можемо надати необхідну інформацію.
  • Агреговані дані: Ми можемо використовувати та передавати агреговані або анонімні дані (які не дозволяють ідентифікувати Вас особисто) для статистичного аналізу, покращення сервісу або маркетингових досліджень.

4. Ваші права

Ви маєте право:

  • Доступ до даних: Запитувати інформацію про те, які Ваші дані ми зберігаємо.
  • Виправлення даних: Вимагати виправлення неточної або неповної інформації.
  • Видалення даних: Запитувати видалення Ваших даних з нашої системи, за винятком тих, що вимагаються для зберігання згідно з законодавством або для вирішення поточних фінансових/ігрових спорів.
  • Відкликання згоди: Відкликати свою згоду на обробку даних у будь-який час, що може призвести до припинення надання послуг.

Для реалізації цих прав зверніться до нашої служби підтримки через Telegram-бота або до адміністратора.

5. Cookies

Ми можемо використовувати файли cookie для покращення Вашого досвіду користування сервісом, аналізу трафіку та персоналізації контенту. Ви можете керувати налаштуваннями файлів cookie у своєму браузері.

6. Зміни до Політики конфіденційності

Ми залишаємо за собою право вносити зміни до цієї Політики безпеки та конфіденційності. Усі зміни будуть опубліковані на цій сторінці, і, за можливості, ми повідомимо Вас про суттєві зміни через Telegram-бота або електронну пошту. Рекомендуємо періодично переглядати цю сторінку для ознайомлення з актуальною інформацією.

7. Зв'язок з нами

Якщо у Вас виникли питання щодо цієї Політики або обробки Ваших даних, будь ласка, зв'яжіться з нами через Telegram-бота або безпосередньо з адміністратором.
