Правила та Рекомендації користування сервісом

1. Загальні положення

Наш сервіс призначений для безпечного, зручного та швидкого продажу ігрового золота WoW через автоматизовану систему з інтеграцією в Telegram.

Користування сервісом означає повну згоду з цими правилами.

2. Telegram-інтеграція

Telegram-бот служить основним інтерфейсом взаємодії. Ви можете:

  • Активувати/деактивувати замовлення;
  • Отримувати сповіщення про нові замовлення;
  • Слідкувати за статусом відправленого золота;
  • Отримувати фінансову статистику.
Рекомендуємо увімкнути сповіщення від бота, щоб не пропустити важливі події.

3. Вимоги до продавців

Продавець повинен:

  • Мати стабільне інтернет-з’єднання та базові знання гри WoW (новачкам буде призначено наставника);
  • Оперативно реагувати на нові замовлення;
  • Дотримуватись внутрішніх інструкцій щодо доставки золота;
  • Дбайливо ставитись до довіри клієнтів та репутації сервісу.

Заборонено:

  • Спам, шахрайство, фальсифікація відправлень;
  • Ігнорування замовлень без попередження;
  • Виставлення золота, якого немає у наявності;
  • Зловживання довірою клієнтів або команди.

4. Виплати

Виплати здійснюються двічі на місяць — 15-го та останнього числа.

Доступні способи:

  • Банківські картки (Україна) — курс Payoneer + комісія 3%;
  • Payoneer — без комісій;
  • Криптовалюта (USDT BEP20 або Binance USDT) — комісія 3%.

Також доступні альтернативні витрати на інші послуги (наприклад, для купівлі бота).

5. Рекомендації щодо продажів

  • Завжди старайтесь ставити **дорого + трейд** — це дає кращу ціну;
  • Якщо потрібно швидко — обирайте **баланс + трейд** або **дешево + трейд**;
  • Лише ті сервери, де погано продається — ставимо "**дешево + трейд**";
  • Рекомендуємо виставляти замовлення частіше. Якщо ви знаходитесь поруч — вмикайте трейд, якщо відходите або залишаєте на ніч — активуйте тільки доставку поштою (mail) без трейду;
  • **Мінімальна загальна вартість для виставлення товару — $2**;
  • Додано вкладку "**Активне замовлення**", де видно поточне замовлення та можна відправити відео;
  • Додано **внутрішній ринок** для купівлі золота між продавцями без ризиків.

6. Нові напрямки розвитку

Сервіс постійно розвивається, пропонуючи нові можливості для взаємодії та заробітку:

  • Наставник — досвідчені гравці допомагають новачкам і отримують 5% прибутку;
  • Рекрутер — залучайте нових користувачів і отримуйте 5%;
  • Оренда персонажів — здавайте або беріть в оренду персонажів (10%).

7. Правила запису відео (Mail і Trade)

7.1 Mail (відправка поштою):

Підготовка:

  • Ховаємо сумки, знімаємо речі з пошти;
  • Видаляємо друзів та ігнор;
  • Купуємо предмет на аукціоні для вкладення в лист;
  • Копіюємо нік покупця з Telegram;
  • Виходимо до меню вибору персонажа (Logout).

Запис:

  • Починаємо з меню вибору персонажа (сервер);
  • Входимо в гру → Social → Add Friend (ctrl+v);
  • Показуємо, що покупця немає в ігнорі;
  • Відкриваємо пошту → вставляємо нік → вкладаємо предмет + золото (до 5–10k в лист);
  • Перевіряємо все і надсилаємо;
  • Виходимо в меню → показуємо сервер і список серверів → завершуємо запис.
**Відео:** До 500 МБ, мінімальні налаштування за шаблоном. Це гарантія вашої оплати.

7.2 Trade (передача трейдом):

  • Додаємо в друзі;
  • Знаходимо клієнта;
  • Включаємо запис;
  • Показуємо сумку до трейду;
  • Передаємо золото через трейд;
  • Показуємо сумку після трейду;
  • Демонструємо друзів/ігнор;
  • Вихід в меню → показ сервера → Change Realm → кінець відео.

8. Підтримка

З усіма запитаннями звертайтесь у Telegram канал спільноти або до Адміністратора.

Слідкуйте за оновленнями — сервіс постійно вдосконалюється.

Ця сторінка є частиною загальних правил та рекомендацій Wow Service Portal.
