Крок 1: Перейдіть на головну сторінку

Для початку, будь ласка, перейдіть до основного розділу нашого сервісу, де ви зможете ознайомитись з доступними опціями.

Крок 2: Натисніть кнопку "Додати сервер"

Натисніть на відповідну кнопку, щоб розпочати процес додавання нового сервера до вашого облікового запису.

Крок 3: Оберіть гру, регіон та сервер

Виберіть зі списку необхідну гру, відповідний регіон та бажаний сервер для вашого замовлення.

Крок 4: Натисніть кнопку "Готово"

Після того, як ви зробили свій вибір, натисніть кнопку "Готово", щоб завершити налаштування замовлення.

Крок 5: Дочекайтесь оновлення цін

Якщо ціни для цього сервера відсутні, зачекайте приблизно 10 хвилин та оновіть сторінку.

Якщо ж ціни вже присутні, переходьте до наступного кроку.

Крок 6: Заповніть інформацію про товар

  • Запас: Наявний запас золота (для Cataclysm вказувати кількість тисяч, наприклад 25000 золота вказати як 25).
  • Стратегія: Залежність ціни від швидкості продажу.
  • Доставка: Пошта або пошта + трейд (чим більше способів доставки, тим швидше надійде замовлення).
  • Вартість замовлення ("Загалом") повинна перевищувати 2$.

Крок 7: Виставлення товару на продаж

  • Опції -> Виставити товар ->Підтвердити операцію:

Після підтвердження операції колір індикатора зміниться на зелений. Тепер ваш товар буде передано на продаж протягом 5 хвилин

  • Опції -> Зупинити продаж -> Підтвердити операцію
Після зняття товару з продажу замовлення може прийти ще протягом 5 хвилин
